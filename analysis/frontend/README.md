# Analysis Dashboard - Frontend Core

This is the core React frontend for the Analysis Dashboard. It is designed to be a high-performance, standalone demo that can be deployed to platforms like Vercel or Netlify.

## 🔗 Quick Links
- **Live Demo:** [https://frontend-swart-alpha-94.vercel.app](https://frontend-swart-alpha-94.vercel.app)
- **Main Project Documentation:** [Refer to the root README](../../README.md)

## 🚀 Scripts

In this directory, you can run:

- `npm run dev`: Runs the app in development mode.
- `npm run build`: Builds the app for production.
- `npm run preview`: Locally preview the production build.
- `npm run lint`: Run linting checks.

## 🏗️ Structure

- `/src/components`: UI components organized by feature (dashboard, upload, common).
- `/src/api`: Mock API layer for standalone operation.
- `/src/hooks`: Custom React hooks for state and data management.
- `/src/constants`: Static data and configuration.

## 🎨 Styling

We use a combination of **Tailwind CSS** for layout and utility-first styling, and **Vanilla CSS** for custom, high-end components and micro-animations.
